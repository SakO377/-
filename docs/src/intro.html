SCHOOL HARNESS — 塾・習い事教室向け オープンソース運営管理システム

教室運営のDXを、月額0円で。

生徒管理・入退室・欠席振替・指導報告・お知らせ配信・月謝請求。有料SaaSの中核機能を、オープンソースで。保護者との連絡はすべてLINEで完結します。

利用料 永久0円  ライセンス費・月額費・生徒数課金、すべてありません

こんなお悩みはありませんか?

  • 欠席連絡の電話対応に授業前の貴重な時間を取られている
  • お知らせのプリントが保護者に届かない・読まれたか分からない
  • 月謝の請求書づくりと入金チェックが毎月の負担になっている
  • 管理システムを入れたいが、月2〜3万円の固定費は小規模教室には重い
  • 子どもの個人情報を外部のサービスに預けることに不安がある

School Harness は、これらをまとめて解決するために作られた、塾・ピアノ・英会話・スイミング・ダンス・そろばん等のあらゆる習い事教室のための運営管理システムです。

主な機能(6つ)

① 生徒・保護者管理

生徒の登録、コース・クラス・タグ管理。招待コードで保護者のLINEと安全に紐付け。きょうだい(1保護者に複数生徒)にも対応。

② 入退室管理

生徒別QRカードを教室のタブレット等で読み取るだけ。専用機器の購入は不要。保護者へLINE通知、履歴のCSV出力も。

③ 欠席・振替連絡

保護者はLINE内フォームから連絡、電話は不要に。教室は一覧で確認し、振替候補日を提案→保護者がワンタップで確定。

④ 指導報告書

テンプレートを選んで入力し、LINEで送信。既読管理付きで「読まれたか」が分かる。教科・単元の事前登録で入力を時短。

⑤ お知らせ一斉配信

全体・クラス別・タグ別のセグメント配信と予約配信。既読・未読も把握でき、「プリントが届かない」問題を解消。

⑥ 月謝・請求管理

生徒ごとの月謝設定、きょうだい割引等の内訳調整、請求書の発行(印刷・PDF)とLINEでの案内、入金の消込管理。

選ばれる7つの理由

1. 利用料が永久に0円(オープンソース)

MITライセンスで公開されるオープンソースソフトウェアです。ライセンス費・月額費・生徒数課金は一切なく、動作に使うCloudflareとLINE公式アカウントも無料枠で運用できる設計です。有料SaaS(相場:月2〜3万円+オプション課金)と比べ、年間で数十万円の固定費削減になります。

2. 保護者はLINEだけ。アプリ不要

保護者に新しいアプリをインストールさせる必要はありません。ふだん使っているLINEに通知が届き、LINE内の画面で欠席連絡から請求書確認まで完結します。導入の最大の壁である「保護者に使ってもらえない」が起きにくい設計です。

3. データは自分の管理下に(子どもの個人情報を外部に預けない)

セルフホスト型のため、生徒・保護者の情報は教室自身のCloudflareアカウント内のデータベースにのみ保存されます。運営会社のサーバーに子どもの情報を預ける構造そのものがありません。CSVエクスポートとバックアップ手順も用意されています。

4. LINEの無料枠内で運用できる「配信数の見える化」

LINE公式アカウントの無料メッセージ枠(月200通)を超えないよう、当月の配信数と残量を管理画面に常時表示。通知は機能ごとにON/OFFでき、OFFでも保護者はLINE内の履歴画面でいつでも確認可能(この方式は無料枠を消費しません)。無料枠を超えそうな配信は自動で停止する安全装置付きです。

5. 専用機器のいらない入退室管理

手持ちのタブレットやパソコンと、市販のQRリーダー(またはカメラ)だけで入退室管理を始められます。カード紛失時はワンクリックで再発行でき、古いカードは自動的に無効になります。

6. AI・自動化に対応した「APIファースト」設計

全機能がREST APIとして公開されており、Claude CodeなどのAIツールから「今月の欠席者を一覧にして」のように自然言語で操作・集計できます。将来の拡張や他システム連携も容易です。

7. プラットフォーム規約を遵守した安心設計

LINEの公式API(Messaging API / LIFF)のみを正規の方法で利用しています。規約回避を目的とした機能は一切なく、アカウント停止などのリスクを避けた設計です。

導入に必要なもの・導入の流れ

必要なのは、いずれも無料で作れる3つのアカウントだけです:LINE公式アカウント(LINE Developers)/ Cloudflareアカウント / GitHubアカウント。

  1. アカウント準備 — 上記3つのアカウントを作成(各10分程度)
  2. セットアップ — 同梱の自動セットアップ(pnpm setup)を実行。対話形式でデータベース作成からLINE連携設定まで進みます。AIアシスタント(Claude Code)に作業を任せることもできます
  3. 教室の初期設定 — 管理画面からクラス・生徒を登録し、保護者に招待コードとLINE友だち追加のご案内を配布
  4. 運用開始 — 入退室カードを配って利用スタート。保護者向けの「つかいかたガイド」(別紙)もご用意しています
ITが得意でなくても大丈夫: 日常の運用(生徒登録・欠席確認・お知らせ配信・請求書発行)は、すべて日本語の管理画面から行えます。プログラミングの知識が必要なのは最初のセットアップだけで、その部分は手順書と自動化スクリプト、AIによる対話サポートを用意しています。

ご留意いただきたいこと

正直にお伝えします: School Harness はセルフホスト型のオープンソースソフトウェアです。サポート窓口を持つ商用サービスと異なり、システムの運用責任(アップデートの適用、データのバックアップ、個人情報の管理)は導入者ご自身にあります。また、LINEの無料メッセージ枠(月200通)を超える通知を行う場合は、LINE公式アカウントの有料プラン(ライトプラン:月5,500円〜)が必要になります。生徒数が多く入退室通知をすべてPushしたい場合等は、無料枠に収める運用ガイド(README)をご確認ください。
