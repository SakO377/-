# docs — 配布用ドキュメント

教室での運用にそのまま使える配布資料です。

| ファイル | 対象 | 用途 |
|---|---|---|
| `School-Harness-つかいかたガイド_保護者生徒向け.pdf` | 保護者・生徒 | LINE連携の初期設定、入退室カード、欠席連絡などの使い方。印刷して配布する想定 |
| `School-Harness-導入のご案内_教室運営者向け.pdf` | 教室運営者 | 機能・特長・コスト比較・導入の流れをまとめた紹介資料 |

## 編集・再生成のしかた

PDFの元データは `src/guide.html` / `src/intro.html` です(教室名の追記や文言変更はこのHTMLを編集してください)。
編集後、Playwright が使える環境で以下を実行するとPDFが再生成されます。

```bash
node docs/src/render.mjs
```
