# 個人情報・データの取り扱い規程(テンプレート)

School Harness を使って教室を運営する事業者向けの、個人情報の取り扱い方針のひな形です。
`【　】` の箇所を自分の教室に合わせて記入し、保護者向けに公開・配布してください。
本ひな形は一般的な内容であり、法的な網羅性を保証するものではありません。必要に応じて専門家にご確認ください。

## 2. 取得する情報

本サービスの運用にあたり、次の情報を取得・保存します。

| 種別 | 具体例 | 保存場所 |
|---|---|---|
| 生徒情報 | 氏名、学年、コース、所属クラス、タグ、成績 | Cloudflare D1(データベース) |
| 保護者情報 | 氏名、続柄、LINEユーザーID | Cloudflare D1 |
| 出欠・連絡 | 入退室記録、欠席・振替連絡、指導報告書 | Cloudflare D1 |
| 請求情報 | 月謝・請求明細・入金状況 | Cloudflare D1 |
| 見込み客情報 | 体験・見学申込の氏名・連絡先 | Cloudflare D1 |
| 操作ログ | 管理者の操作履歴(誰が・いつ・何を) | Cloudflare D1 |

クレジットカード番号・銀行口座などの決済情報は本サービスでは取り扱いません
(決済を行う場合は外部の決済サービスをご利用ください)。

## 3. 利用目的

- 出欠管理・月謝請求・保護者への連絡など、教室運営に必要な範囲での利用。
- 体験・見学申込への対応、入会案内。
- サービスの不正利用防止・トラブル対応(操作ログの確認)。

上記の目的の範囲を超えて利用したり、本人の同意なく第三者へ提供したりしません。

## 4. 第三者提供・委託先

サービスの提供にあたり、次の外部サービスを利用します(データの保管・送信の委託)。

- **Cloudflare(米国)**: アプリケーションの実行およびデータベース(D1)の保管。
- **LINE(LINEヤフー株式会社)**: 保護者への通知配信(LINE連携を利用する場合)。

## 5. 保管期間・削除

- 在籍中および退会後【　◯　】年間保管し、その後は削除します。
- 保護者・本人からの求めに応じて、保有する個人情報の開示・訂正・削除に対応します。
- 生徒データは管理画面から削除でき、削除すると関連する出欠・報告書・請求も削除されます。
- データベースのバックアップは `wrangler d1 export` で取得し、【　保管方法　】で安全に保管します。

## 6. 安全管理措置

本サービスでは次の技術的対策を用意しています。運用側でも適切に設定してください。

- **アクセス制御**: 管理画面はスタッフごとのAPIキー、またはパスワードログインで保護。
- **2段階認証(TOTP)**: 各スタッフが「設定」画面から有効化できます。**責任者は必ず有効化してください。**
- **アクセス元制限**: 教室の固定IPのみ許可する設定(`ADMIN_IP_ALLOWLIST`)が可能です。
- **操作ログ**: 更新・削除操作を記録し、オーナーが「操作ログ」画面で確認できます。
- **APIキーのローテーション**: 漏洩の疑いがある場合、「設定」画面からAPIキーを再発行できます。
- **通信の暗号化**: すべての通信は HTTPS で暗号化されます。

## 7. 漏洩等が発生した場合

個人情報の漏洩・滅失・毀損が判明した場合は、速やかに影響範囲を確認し、
対象の保護者へ連絡するとともに、必要に応じて個人情報保護委員会等へ報告します。
